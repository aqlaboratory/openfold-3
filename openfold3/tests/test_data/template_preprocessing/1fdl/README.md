# 1fdl template preprocessing fixture

Real inputs for the train-mode tests in
`tests/core/data/pipelines/preprocessing/test_template.py`.
Query: PDB 1fdl (IgG1 D1.3 Fab light chain, heavy chain, hen egg-white lysozyme;
released 1991-10-15).

| Path | Contents |
|---|---|
| `representatives.fasta` | Alignment representatives `1fdl_A`/`1fdl_B`/`1fdl_C` (1fdl label chains) and their canonical SEQRES sequences |
| `raw_pdb70.m8` | The selected hits as ColabFold returns them: one table for all three chains (column 1 is ColabFold's query index, 101-103), author chain IDs |
| `template_alignments/<rep_id>/colabfold_template.m8` | Rows of the real ColabFold pdb70 hit tables for each chain, cut down to the hits below |
| `template_structures/<pdb_id>.cif.gz` | The hit structures, as downloaded from RCSB |
| `golden/<rep_id>.npz` | Template cache entries from predict mode on the same inputs, with no release-date filtering |
| `regenerate_fixture.py` | Rebuilds all of the above |

Selected hits (row in the full hit table, release date):

| rep_id | Hits |
|---|---|
| `1fdl_A` (light) | 1fdl (1, 1991-10-15), 1qbl (3, 1998-12-02), 1jhk (5, 2001-10-10) |
| `1fdl_B` (heavy) | 1fdl (1, 1991-10-15), 1qbl (5, 1998-12-02), 3hfm (62, 1989-07-12) |
| `1fdl_C` (lysozyme) | 1ior (1, 2001-04-11), 7ynv (5, 2022-09-21), 5lyz (7, 1977-04-12) |

The `.m8` rows are unmodified except for the chain ID in column 2. ColabFold names
hits by author chain ID (`1fdl_L`); the template preprocessor expects label chain IDs
(`1fdl_A`), which `align-msa-server` produces via `remap_colabfold_template_chain_ids`.
`regenerate_fixture.py` applies the same remapping from each structure's
`pdbx_poly_seq_scheme`, which gives the same mapping as the RCSB API.

The full hit tables were generated by the ColabFold MSA server (via atomworks'
`make_msas_colabfold_server_batch` with `use_templates=True`) and are not committed.
